POKASAH TEA — WEBSITE LANDING PAGE

CARA MENGGANTI GAMBAR
1. Buka folder assets.
2. Ganti gambar dengan foto milikmu.
3. Gunakan nama file yang sama agar tidak perlu mengubah kode:
   - hero.jpg          = foto utama/banner
   - video-thumbnail.jpg = gambar sampul video
   - pokak.jpg         = foto tanaman pokak
   - packaging.jpg     = foto kemasan gelatin + cangkang telur
   - tea-glass.jpg     = foto teh setelah diseduh
   - eco.jpg           = foto/ilustrasi konsep pemanfaatan cangkang telur
4. Jika format foto PNG, ubah nama file di index.html sesuai nama file baru.

CARA MENGGANTI TAUTAN
Buka script.js, lalu ubah bagian LINKS:
- video: tautan video gabungan (YouTube/Google Drive/video publik)
- email: alamat email
- whatsapp: nomor WhatsApp format internasional, contoh 6281234567890
- instagram: tautan akun Instagram

MENJALANKAN WEBSITE
- Cara mudah: klik dua kali index.html untuk melihat di browser.
- Agar bisa diakses publik: upload seluruh isi folder ini ke repository GitHub,
  lalu aktifkan GitHub Pages pada Settings > Pages.

CATATAN
Website ini menggunakan HTML, CSS, dan JavaScript biasa. Semua gambar dapat diganti
dengan mengganti file di folder assets. Klaim produk di halaman dibuat deskriptif
berdasarkan informasi yang diberikan; sesuaikan lagi dengan hasil pengujian produk.
